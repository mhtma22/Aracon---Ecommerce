# Catálogo de Estilos y Tipologías Web - Referencia Estándar

Este documento sirve como la guía oficial de estilos y tipologías web para todas las páginas y componentes creados o modificados en este repositorio.

---

### 1. Páginas de Destino y Conversión (Landing Pages)
- **Lead Capture Page:** Enfocada en capturar datos de usuarios (correos, teléfonos) a cambio de un recurso gratuito. Formulario directo y pocos elementos de salida.
- **Sales Page:** Diseñada para vender un producto o servicio específico mediante un argumento de venta largo (*long-form*), testimonios, preguntas frecuentes y CTAs claros.
- **Splash Page:** Página de bienvenida previa al sitio principal para anuncios importantes, selección de idioma o cuenta regresiva.

---

### 2. Páginas Corporativas e Institucionales
- **Corporate / Business Website:** Web clásica de una empresa (Inicio, Servicios, Sobre Nosotros, Blog, Contacto).
- **Portfolio Page:** Galería visual o estudios de caso para creativos, diseñadores o desarrolladores.
- **SaaS / Product Page:** Diseñada para software, con características, beneficios, tablas de precios y registros.

---

### 3. Comercio Electrónico (E-commerce)
- **Tienda Online (Storefront):** Listados de productos, filtros, páginas de detalle, carrito y pasarela de pago.
- **Directorio o Marketplace:** Plataformas complejas que agrupan múltiples vendedores o listados (bienes raíces, empleo, reservas).

---

### 4. Contenido, Medios y Comunidad
- **Blog / Revista Digital:** Estructuras optimizadas para lectura de artículos, categorización y espacios publicitarios.
- **Foro o Comunidad:** Basado en perfiles de usuario, hilos de discusión, comentarios y moderación.
- **Documentación / Wiki:** Navegación lateral jerárquica, barras de búsqueda rápidas y bloques de código.

---

### 5. Estilos Visuales y de Interfaz (Tendencias de Diseño)
- **Minimalista / Clean:** Espacios en blanco amplios, tipografía elegante y enfoque total en el contenido.
- **Bento Grid:** Cuadrícula modular con tarjetas de diferentes tamaños (cuadrados y rectángulos) para mostrar características de forma limpia.
- **Claymorphism:** Elementos inflados y tridimensionales con sombras suaves, bordes redondeados y colores pasteles o vibrantes.
- **Aurora / Mesh Gradient:** Fondos abstractos y fluidos que mezclan múltiples colores vivos difuminados.
- **Brutalismo / Anti-Design:** Diseños crudos, asimétricos, tipografías pesadas y colores contrastantes.
- **Glassmorphism:** Efectos visuales de cristal esmerilado con desenfoque de fondo y transparencias.
- **Editorial / High Fashion:** Inspirado en alta costura, tipografías serif elegantes, espacios amplios y asimetría.
- **Retro / Y2K / Synthwave:** Estética nostálgica de los 90s/2000s o cyberpunk, colores saturados y tipografías pixeladas.
- **Maximalismo:** Mezcla de colores estridentes, tipografías variadas y capas múltiples para saturar visualmente.
- **Dark Mode / Cyberpunk:** Interfaces oscuras con acentos de colores neón o vibrantes orientadas a tecnología y gaming.

---

### Reglas de Aplicación
- **Diseño Responsivo (Mobile-First):** Utilizar estructuras CSS Grid y Flexbox o clases de Tailwind CSS garantizando adaptabilidad fluida.
- **Componentes Interactivos:** Menús adaptativos, carruseles, modales y validaciones visuales.
- **Protección de la ruta `/admin`:** No modificar la ruta `/admin` sin autorización explícita.
